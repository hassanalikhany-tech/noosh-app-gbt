# آمادگی انتشار نوش‌اپ در Google Play

آخرین بازبینی: ۲۷ اکتبر ۲۰۲۶

## وضعیت فنی

- پوستهٔ Android با Capacitor 8 به پروژه اضافه شده است.
- شناسهٔ فعلی بسته: `com.cydevit.nooshapp`؛ این شناسه پس از انتشار قابل تغییر نیست و باید پیش از ساخت صفحهٔ Play Console نهایی شود.
- پروژه با `compileSdkVersion = 36` و `targetSdkVersion = 36` ساخته شده است.
- نسخهٔ اولیهٔ Android فعلاً `versionCode 174300` و `versionName 17.43.0` دارد.
- APK آزمایشی debug ساخته شده است؛ این فایل برای نصب مستقیم روی Android است و برای بارگذاری در Play Console مناسب نیست.
- خروجی native با حالت `native` ساخته می‌شود؛ chunkهای پنل مدیریت در APK قرار نمی‌گیرند و مسیر `/admin` در اپ Android فقط پیام «پنل مدیریت فقط در نسخهٔ وب در دسترس است» نشان می‌دهد.
- داده‌های شخصی در حافظهٔ داخلی WebView همان برنامه می‌مانند. نصب Android از مرورگر جدا است و داده‌ها بین این دو منتقل نمی‌شوند.
- سرویس‌ورکر PWA در Android native خاموش است. رسپی‌ها در بستهٔ برنامه قرار دارند؛ ارسال بازخورد و درخواست اشتراک رسپی به Netlify نیازمند اینترنت است.
- درخواست‌های عمومی اپ بومی برای ارسال نظر، رسپی و دریافت اعلان‌ها از مبدأ `https://localhost` مجاز شده‌اند. مسیرهای مدیریتی همچنان همان کنترل مبدأ و نشست قبلی را دارند.

## ساخت محلی

نیاز است Android Studio نسخهٔ 2025.2.1 یا بالاتر، SDK Platform 36، Android SDK Build Tools و JDK همراه Android Studio نصب باشند. پس از نصب و تنظیم Android SDK:

```powershell
npm install
npm run android:sync
npm run android:open
```

برای ساخت بستهٔ Release محلی، ابتدا کلید Upload اختصاصی بسازید و آن را خارج از مخزن نگه دارید. در همان نشست PowerShell متغیرهای محیطی زیر را تنظیم کنید؛ مقادیر را در فایل پروژه یا Git ننویسید:

```powershell
$env:NOOSH_UPLOAD_STORE_FILE = 'C:\secure\noosh-upload.jks'
$env:NOOSH_UPLOAD_STORE_PASSWORD = '<store-password>'
$env:NOOSH_UPLOAD_KEY_ALIAS = 'noosh-upload'
$env:NOOSH_UPLOAD_KEY_PASSWORD = '<key-password>'
npm run android:bundle
```

خروجی AAB امضاشده در `android/app/build/outputs/bundle/release/` قرار می‌گیرد. اگر متغیرها تنظیم نشده باشند، Gradle بستهٔ Release را بدون امضا می‌سازد و Play Console آن را نمی‌پذیرد. کلید امضا و رمز آن هرگز نباید وارد GitHub شوند.

## موارد باقی‌مانده پیش از ارسال به Google Play

1. نهایی‌کردن شناسهٔ بسته و نام نمایش فروشگاه.
2. حساب Google Play Console هنوز ساخته نشده است؛ صفحهٔ بازشده برای حساب مالک `hassan.alikhany@gmail.com` مرحلهٔ انتخاب نوع حساب را نشان می‌دهد. مالک حساب باید خودش «شخصی» یا «سازمانی» را بر اساس وضعیت حقوقی واقعی انتخاب کند و ثبت‌نام را کامل کند. ثبت‌نام Play Console هزینهٔ یک‌بارهٔ ۲۵ دلار آمریکا دارد؛ انتشار و نصب اپ می‌تواند برای کاربران رایگان باشد.
3. اگر حساب شخصی تازه ساخته شود، Google برای دسترسی انتشار عمومی حداقل ۱۲ آزمایشگر در Closed testing به‌مدت پیوستهٔ ۱۴ روز می‌خواهد؛ سپس باید درخواست دسترسی Production ثبت و تأیید شود. جزئیات نهایی به نوع و سابقهٔ حساب بستگی دارد.
4. برای توسعهٔ پایدار، نصب Android Studio نسخهٔ جاری، SDK 36 و JDK سازگار پیشنهاد می‌شود. در این نوبت ابزار خط فرمان Android و JDK 21 موقتاً دریافت شدند و APK آزمایشی ساخته شد؛ Android Studio یا emulator نصب نشده است.
5. بررسی CORS و توابع عمومی پس از انتشار همین commit روی Netlify، با نصب واقعی Android و آزمون ارسال نظر، اعلان‌ها و درخواست اشتراک رسپی.
6. نصب APK debug روی گوشی Android یا emulator و آزمایش اجرای آفلاین، بازگشت از صفحهٔ رسپی، انتخاب/گرفتن تصویر، چرخش صفحه، صفحه‌خوان، حذف داده و بازیابی پشتیبان.
7. ساخت کلید Upload و ثبت Play App Signing در Play Console؛ کلید محرمانه خارج از Git نگهداری شود.
8. تکمیل صفحهٔ فروشگاه: آیکن 512×512، تصویر ویژهٔ 1024×500، حداقل دو تصویر صفحهٔ موبایل، توضیحات کوتاه/کامل، زبان، دسته‌بندی و نشانی پشتیبانی.
9. تکمیل App content: رده‌بندی سنی، مخاطب هدف، تبلیغات (اپ تبلیغ ندارد)، سیاست حریم خصوصی زنده، و Data safety مطابق با ارسال اختیاری بازخورد/رسپی و پردازش فنی Netlify.
10. ساخت AAB نهایی با شناسهٔ بستهٔ تأییدشده و کلید Upload امن؛ APK آزمایشی debug جایگزین AAB امضاشده نمی‌شود.
11. بارگذاری AAB در Closed testing و بررسی گزارش‌های پیش‌راه‌اندازی؛ حساب شخصی تازه باید ۱۲ آزمایشگر را حداقل ۱۴ روز پیوسته در گروه نگه دارد، سپس برای Production access درخواست بدهد.

## متن پیشنهادی صفحهٔ Play

**نام:** نوش‌اپ | برنامه‌ریز غذا و آشپزخانه

**توضیح کوتاه:** دستورهای ایرانی و بین‌المللی، پیشنهاد غذا، برنامه‌ریزی و مدیریت موجودی آشپزخانه.

**توضیح کامل:**

نوش‌اپ همراه آشپزخانهٔ شماست: میان صدها دستور غذای ایرانی و بین‌المللی جست‌وجو کنید، مواد لازم و مراحل پخت را ببینید، برای امروز یا هفتهٔ پیش‌رو برنامه بچینید و فهرست خرید بسازید. اگر بخواهید، موجودی آشپزخانه را ثبت کنید تا پیشنهادها و کسری مواد با انبارتان هماهنگ شوند؛ اگر هم نخواهید، می‌توانید بدون ثبت انبار از پیشنهادها و رسپی‌ها استفاده کنید. تنظیمات، موجودی، برنامه‌ها و رسپی‌های خصوصی روی همان دستگاه ذخیره می‌شوند. ارسال نظر و درخواست انتشار عمومی رسپی اختیاری است و برای بررسی به سرویس نوش‌اپ فرستاده می‌شود.

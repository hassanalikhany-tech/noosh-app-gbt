# نوش‌اپ

نوش‌اپ یک برنامهٔ فارسی برای جست‌وجوی رسپی، برنامه‌ریزی غذا و مدیریت اختیاری موجودی آشپزخانه است. کتابخانهٔ رسپی‌ها همراه برنامه ارائه می‌شود و استفاده از امکانات اصلی به ساخت حساب نیاز ندارد.

## اجرای نسخهٔ وب

با Node.js و npm اجرا کنید:

```sh
npm ci
npm run dev
```

برای ساخت نسخهٔ وب در `dist`:

```sh
npm run lint
npm run build
```

## ساخت Android

پوستهٔ Android با Capacitor ساخته شده است. برای همگام‌سازی کد وب و پروژهٔ Android به Android Studio، JDK سازگار و Android SDK 36 نیاز دارید:

```powershell
npm ci
npm run android:sync
npm run android:open
```

راهنمای ساخت AAB، امضای امن، وضعیت Google Play و موارد باقیمانده در [آمادگی Google Play](docs/google-play-readiness.md) است.

## ذخیره‌سازی و سرویس‌های آنلاین

تنظیمات شخصی، موجودی، برنامه، فهرست خرید و رسپی‌های خصوصی روی همان دستگاه ذخیره می‌شوند. پاک‌کردن داده‌های سایت یا برنامه می‌تواند آن‌ها را حذف کند؛ برای انتقال یا نگهداری نسخهٔ پشتیبان از ابزار پشتیبان‌گیری داخل برنامه استفاده کنید.

ارسال اختیاری بازخورد، دریافت اعلان‌های عمومی و درخواست انتشار رسپی از توابع Netlify استفاده می‌کنند. درخواست‌های انتشار رسپی پس از تأیید مدیر به کتابخانهٔ عمومی افزوده می‌شوند. سیاست داده در [`public/privacy.html`](public/privacy.html) توضیح داده شده است.

جزئیات فنی و مواردی که هنوز روی دستگاه واقعی تأیید نشده‌اند در [`VERIFICATION.md`](VERIFICATION.md) آمده است.

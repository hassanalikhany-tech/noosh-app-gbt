# نوش — نسخهٔ ۱۷.۲۹

دستیار فارسی آشپزی و برنامه‌ریزی غذا، با React و TypeScript.

## اجرا

به Node.js و npm نیاز دارید. در پوشهٔ پروژه اجرا کنید:

```sh
npm ci
npm run dev
```

سپس نشانی نمایش‌داده‌شده در ترمینال را باز کنید. دکمهٔ «ورود مهمان؛ بدون ثبت‌نام» امکان بررسی برنامه را بدون حساب فراهم می‌کند.

```sh
npm run lint
npm test
npm run build
npm run preview
```

خروجی قابل میزبانی در `dist` ساخته می‌شود. فایل `index.html` را با دوبار کلیک اجرا نکنید؛ از سرور محلی یا میزبانی وب استفاده کنید.

## تغییرات این نسخه

- صفحهٔ اصلی مستقیماً روی «آشپزخانهٔ من» باز می‌شود؛ پیشنهادها بر اساس موجودی، مقدار مواد، کمبودها و تعداد نفرات مرتب می‌شوند.
- ثبت سریع نام دلخواه، مقدار و واحد مواد؛ افزایش موجودی اقلام تکراری و افزودن با یک لمس از فهرست دسته‌بندی‌شده.
- نمایش عکس واقعی غذای ایرانی در هیرو، وضعیت انبار و شمارش غذاهای کتابخانه.
- همگام‌سازی کتابخانهٔ عمومی برای مهمان و کاربر از Firebase و CSV پشتیبان؛ نمایش دسته‌ها و کشورها از دادهٔ واقعی و اعلام خطای شبکه.
- ساده‌سازی آشپزخانه به یک نمای یکپارچهٔ انبار؛ انتخاب از فهرست آماده مستقیماً موجودی را به‌روزرسانی می‌کند و مسیر جداگانهٔ «انتخاب سریع» حذف شده است.
- دسته‌بندی مواد به گروه‌ها و زیرگروه‌های باز و بسته‌شونده، همراه با جستجوی هم‌زمان در همهٔ گروه‌ها.
- متعادل‌سازی عرض ستون‌های انبار و افزودن کارت شروع سریع با مواد پرکاربرد برای پر کردن فضای خالی انبار.
- بازطراحی صفحهٔ اصلی، برنامه‌ریز و صفحهٔ ورود با پالت سبز، تایپوگرافی فارسی و دسترسی‌های سریع.
- کارت‌های خواناتر، کنترل‌های قابل استفاده در موبایل، فوکوس صفحه‌کلید و پشتیبانی از کاهش حرکت.
- ورود مهمان با ذخیرهٔ برنامه، علاقه‌مندی‌ها، موجودی و لیست خرید در همان مرورگر، جدا از حساب ابری.
- برنامهٔ روزانه، هفتگی و دقیقاً ۳۰ روزه؛ امکان بازگرداندن آخرین برنامه در همان نشست.
- اعمال قطعی فیلتر علاقه‌مندی، دسته، زمان، طبع و چالش فعال؛ بدون جایگزینی خاموش با غذاهای نامرتبط.
- جستجو در نام، توضیح و مواد اولیه؛ یکسان‌سازی «ی/ي» و «ک/ك» و فاصله‌ها.
- پذیرش ارقام فارسی و عربی در شماره موبایل و کد تأیید و اعتبارسنجی شمارهٔ ایران.
- ساخت لیست خرید بدون کم کردن مواد موجودی؛ کسر موجودی به ثبت پخت مربوط است.
- حفظ دستورهای محلی هنگام همگام‌سازی و استفاده از نشانی تصویر انتخاب‌شده پیش از تصویر حدسی.
- ساخت CSS در زمان build، حذف Tailwind CDN و importmap اضافی؛ بارگذاری جداگانهٔ بخش مدیریت و تنظیمات.

## بررسی انجام‌شده

`npm run lint` برای TypeScript، `npm test` برای ۱۶ بررسی منطق برنامه‌ریزی، فیلترها، متن فارسی و ذخیرهٔ مهمان، و `npm run build` برای خروجی انتشار.

در مرورگر نیز ورود مهمان، ساخت برنامهٔ روزانه و هفتگی، علاقه‌مندی، بازگردانی برنامه، انتقال مواد به خرید، ماندگاری پس از بارگذاری مجدد، جستجوی «كشك» و باز شدن دستور با صفحه‌کلید بررسی شده است. چیدمان صفحهٔ اصلی در عرض ۳۹۰ پیکسل سرریز افقی ندارد.

## مرز نسخهٔ محلی و انتشار عمومی

این نسخه یک بهبود قابل اجرا روی کد تحویلی است. اتصال واقعی سرویس‌های زیر در این محیط تأیید نشده است:

- احراز هویت پیامکی: کد اولیه OTP را در مرورگر تولید و نگهداری می‌کند و مسیر حساب آزمایشی دارد؛ این روش تأیید مالکیت شمارهٔ موبایل نیست. پیش از انتشار باید تولید و بررسی OTP، محدودسازی درخواست و تعیین نقش مدیر به سرور مورد اعتماد منتقل شود.
- قواعد Firebase و دسترسی مدیر باید سمت سرور بررسی شوند؛ مخفی بودن دکمه‌های مدیریت مجوز امنیتی محسوب نمی‌شود.
- کلید Gemini در تنظیمات اولیهٔ Vite داخل خروجی مرورگر قرار می‌گیرد؛ برای انتشار عمومی فراخوانی هوش مصنوعی باید از واسط سرور انجام شود.
- پرداخت و تسویه باید با سرویس واقعی و تأیید تراکنش در سرور آزمایش شوند.

حالت مهمان هیچ مجوز مدیریت یا اشتراک ابری ایجاد نمی‌کند و پروفایل آن به Firebase ارسال نمی‌شود. پاک کردن داده‌های مرورگر، داده‌های مهمان را حذف می‌کند. تصاویر غذا و فونت‌ها ممکن است برای بارگذاری به اینترنت نیاز داشته باشند. این نسخه به‌عنوان PWA آفلاین کامل ارائه نشده است.

جزئیات آزمون و محدودیت‌ها در `VERIFICATION.md` آمده است.
- مقدار اقلام انبار بدون محدودیت پله‌ای وارد می‌شود؛ برای مقدارهای مثبت اعشاری و بزرگ، خطای step مرورگر نمایش داده نمی‌شود.
- هر قلم انبار کارت جدا، قابل انتخاب با ماوس و صفحه‌کلید، و بازخورد دیداری واضح دارد.
- هیروی برنامهٔ غذایی بر چیدن برنامهٔ روزانه، هفتگی و ماهانه و افزودن کسری مواد به فهرست خرید تمرکز دارد.
- هیروی برنامهٔ غذایی عکس زرشک‌پلو با مرغ ایرانی را کنار توضیح برنامه‌ریزی نشان می‌دهد؛ مواد لازم پس از کسر موجودی با مقدار و واحد خرید به فهرست اضافه می‌شوند.
